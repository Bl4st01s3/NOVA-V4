This tool scrapes and extracts readable text from web pages. Use it when the user provides a URL and asks you to read, summarize, or learn from a specific website (like documentation, news articles, or wiki pages). Note: If the user explicitly asks you to 'remember' or 'learn' the facts from the website for the future, you should first run the web_scraper to read the site, and then proactively run the memory_manager tool to save the most critical facts to your long-term memory.
